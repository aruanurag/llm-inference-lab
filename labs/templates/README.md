# Lab Template

Use this structure for future labs:

```text
labs/NN-topic-name/
├── README.md
├── setup.md
├── run.sh
├── benchmark.py
├── collect_metrics.py
└── results/
```

Each lab should be a tutorial:

- state the question
- run the smallest useful experiment
- record the measurement
- change one variable
- compare the result
- write down the observation
